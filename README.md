# Turan Bot - Telegram Bot для заказов и учёта

Полнофункциональный Telegram-бот для управления заказами, учёта остатков и аналитики продаж.

## 🚀 Функциональность

- ✅ **Регистрация и авторизация** - Создание аккаунта и вход по логину/паролю
- ✅ **Инлайн-интерфейс** - Полностью кнопочное управление, никаких команд
- ✅ **Каталог товаров** - Просмотр номенклатуры с ценами и быстрым добавлением в заказ
- ✅ **Создание заказов** - Интуитивное добавление товаров с выбором количества
- ✅ **Управление заказами** - Просмотр, подтверждение и отмена заказов
- ✅ **Учёт остатков** - Удобное обновление складских остатков с быстрыми кнопками
- ✅ **Умная навигация** - Кнопка "Назад" в каждом разделе
- 🔄 **Оплата заказов** (в разработке)
- 🔄 **Аналитика продаж** (в разработке)
- 🔄 **Автозаказ** (в разработке)

## 📋 Требования

- Python 3.11+
- SQLite (или PostgreSQL для продакшена)
- Telegram Bot Token

## 🛠 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Allexndr/Turan_bot.git
cd Turan_bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=ваш_telegram_bot_token
DATABASE_DSN=sqlite+aiosqlite:///./turan.db
```

### 4. Инициализация базы данных
```bash
PYTHONPATH=. python3 scripts/setup_db.py
```

### 5. Запуск бота
```bash
PYTHONPATH=. python3 main.py
```

## 📱 Как пользоваться

### Первый запуск
1. Найдите бота в Telegram
2. Отправьте `/start`
3. Выберите "📝 Создать аккаунт" для регистрации или "🔑 Войти в систему"
4. Тестовые аккаунты:
   - **Логин**: `test` **Пароль**: `test`
   - **Логин**: `testuser` **Пароль**: `password123`

### Интерфейс
- **Только инлайн-кнопки** - Никаких команд вводить не нужно
- `/start` - Единственная команда для запуска бота
- **Полная навигация** - Все действия выполняются через кнопки
- **Кнопка "Назад"** - В каждом разделе для удобной навигации

### Создание заказа
1. Нажмите "🛒 Заказы" в главном меню
2. Выберите "➕ Создать новый заказ"
3. Просматривайте товары и добавляйте их кнопками
4. Выбирайте количество кнопками или вводите вручную
5. Подтверждайте заказ

### Управление остатками
1. Нажмите "📦 Остатки" в главном меню
2. Выберите товар для изменения остатка
3. Используйте быстрые кнопки (0, 10, 20, 50, 100, 200) или введите вручную

## 🔧 Разработка

### Добавление новых пользователей
```python
from app.services.auth import create_user
await create_user("newuser", "password456")
```

### Добавление товаров
```python
from app.models import Product
from app.database import autosession

async with autosession() as session:
    product = Product(name="Новый товар", package="1 шт", price=100.0)
    session.add(product)
    await session.commit()
```
