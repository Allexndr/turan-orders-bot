# Деплой Telegram бота на Vercel

## 🚀 Инструкция по деплою

### 1. Подготовка

1. Убедитесь, что код загружен на GitHub
2. Создайте аккаунт на [Vercel](https://vercel.com)
3. Подключите ваш GitHub репозиторий

### 2. Настройка переменных окружения

В настройках проекта Vercel добавьте:

```
BOT_TOKEN=ваш_телеграм_токен
MONGODB_URL=ваша_строка_подключения_mongodb
DATABASE_NAME=turan
```

### 3. Деплой

1. Vercel автоматически задеплоит ваш проект
2. Получите URL вашего деплоя (например: `https://turan-bot.vercel.app`)

### 4. Настройка веб-хука

1. Отредактируйте файл `setup_webhook.py`
2. Замените `your-vercel-app` на имя вашего проекта
3. Запустите скрипт:

```bash
python setup_webhook.py
```

### 5. Важные особенности

⚠️ **Ограничения Vercel:**
- Serverless функции имеют лимит времени выполнения (10 сек для Hobby)
- Подходит для простых ботов с быстрыми операциями
- Для сложных операций лучше использовать Railway, Heroku или VPS

✅ **Альтернативы для постоянной работы:**
- **Railway** - бесплатный тир, поддержка долгих процессов
- **Heroku** - классический вариант
- **DigitalOcean App Platform** - простой деплой
- **VPS** - полный контроль

### 6. Мониторинг

- Логи доступны в панели Vercel
- Функции автоматически "засыпают" при отсутствии запросов
- Первый запрос после "сна" может быть медленным (cold start)

## 🔧 Для продакшена

Рекомендуется использовать Railway или VPS для стабильной работы:

```bash
# Railway
npm install -g @railway/cli
railway login
railway init
railway up
```
